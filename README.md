# LinguaDetect

Сайт, который определяет язык текста. 10 языков: русский, английский, немецкий, французский, испанский, итальянский, португальский, нидерландский, польский, турецкий.

Модель: TF-IDF по символьным n-граммам (2–5) + LinearSVC, датасет [WiLI-2018](https://zenodo.org/records/841984). Интерфейс: Gradio.

## Что лежит в репозитории

| Файл | Зачем |
|---|---|
| `app.py` | сайт (интерфейс, дизайн, горячие клавиши) |
| `linguadetect_model.joblib` | обученная модель из Colab |
| `requirements.txt` | библиотеки (создаётся ячейкой экспорта в Colab) |
| `render.yaml` | настройки для Render (необязательно) |

## Запуск на компьютере

```
pip install -r requirements.txt
python app.py
```

Сайт откроется на http://localhost:7860

## Публикация на Render

1. Загрузи файлы в репозиторий на GitHub.
2. На render.com: **New → Web Service** → выбери репозиторий.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python app.py`
5. Instance Type: **Free** → Deploy.

Если сборка падает из-за версий библиотек, в Environment добавь переменную `PYTHON_VERSION` с той версией Python, что напечатала ячейка экспорта в Colab (например `3.12.3`).

Бесплатный сервис засыпает после 15 минут без заходов, первый запуск после сна занимает около минуты.

## Горячие клавиши

`Ctrl/⌘ + Enter` определить язык · `/` поле ввода · `C` очистить · `1–5` разделы · `0` наверх · `T` тема · `S` настройки · `+` / `−` размер текста · `?` справка
